# Brand X Lucknow: dealership website

New and certified used car browsing with an on-road price breakup by city, EMI calculator,
test-drive booking, a lead inbox with response timers and AI-assisted reply drafts, and an
admin page for prices and stock.

- Live app: https://dealership.vercel.app
- How to run it, environment variables and demo logins: see [deployment.md](./deployment.md)

Built with Next.js, TypeScript, Tailwind CSS, Prisma and PostgreSQL (Neon). All data is sample data.
